# CZSC 项目使用指南

## 项目概述

**CZSC** = 缠中说禅 (Chan Zhong Shuo Chan) 技术分析工具库

**核心功能**：
- 缠论技术分析（笔、线段、中枢）
- CTA 策略回测
- 信号-事件-交易体系
- 可视化报告生成

---

## 核心概念体系

```
┌─────────────────────────────────────────────────────┐
│                  信号-事件-交易体系                    │
├─────────────────────────────────────────────────────┤
│  信号(Signal)  →  事件(Event)  →  持仓(Position)    │
│     ↓                ↓                ↓             │
│  技术指标状态      信号逻辑组合      开平仓策略       │
│  如:日线笔向上     AND/OR/NOT       多头/空头        │
└─────────────────────────────────────────────────────┘
```

## 三种主要使用方式

### 方式一：CTA 策略研究（最常用）

**适用场景**：开发、回测、优化交易策略

```python
from czsc import CTAResearch, CzscStrategyBase, Event, Position
from czsc.mock import generate_symbol_kines
from czsc import format_standard_kline, Freq

# 1. 定义策略
class MyStrategy(CzscStrategyBase):
    @property
    def positions(self):
        # 定义开多条件：日线笔向上
        long_event = Event.load({
            "operate": "开多",
            "signals_all": ["日线_D1_表里关系V230101_向上_任意_任意_0"],
            "signals_any": [],
            "signals_not": [],
        })
        
        # 定义开空条件：日线笔向下
        short_event = Event.load({
            "operate": "开空", 
            "signals_all": ["日线_D1_表里关系V230101_向下_任意_任意_0"],
            "signals_any": [],
            "signals_not": [],
        })
        
        # 创建持仓策略
        pos = Position(
            name="日线笔方向策略",
            symbol=self.symbol,
            opens=[long_event, short_event],
            exits=[],           # 平仓事件（可选）
            interval=3600*4,    # 持仓间隔
            timeout=16*30,      # 超时时间
            stop_loss=500,      # 止损点数
        )
        return [pos]

# 2. 创建研究对象
bot = CTAResearch(
    results_path='/tmp/cta_results',
    signals_module_name='czsc.signals',
    strategy=MyStrategy,
    read_bars=read_mock_bars,  # 数据读取函数
)

# 3. 执行回测
symbols = ['000001', '000002', '000003']
bot.backtest(
    symbols=symbols,
    max_workers=1,      # 并行进程数
    bar_sdt='20180101', # K线开始日期
    edt='20230101',     # 结束日期
    sdt='20200101',     # 策略开始日期
)
```

### 方式二：信号优化

**适用场景**：寻找最优的信号组合

```python
from czsc.traders.optimize import OpensOptimize, ExitsOptimize

# 入场信号优化
oop = OpensOptimize(
    symbols=symbols,
    files_position=position_files,      # 基础策略配置
    candidate_signals=[                 # 候选信号
        "日线_D1MACD12#26#9_BS辅助V230313_多头_任意_任意_0",
        "日线_D1MO20_状态V230915_多头_任意_任意_0",
        "日线_D1KDJ9#3#3_状态V230914_多头_任意_任意_0",
    ],
    read_bars=read_bars,
    results_path='/tmp/optimize',
)
oop.run()
```

**优化逻辑**：
- 遍历所有候选信号组合
- 回测每个组合的表现
- 输出最优信号组合

### 方式三：生成分析报告

**适用场景**：策略绩效可视化、交易记录分析

```python
from czsc.utils.html_report_builder import HtmlReportBuilder

# 创建报告
builder = HtmlReportBuilder(title="策略绩效报告")

# 添加头部信息
builder.add_header({
    "策略名称": "日线笔方向策略",
    "回测区间": "2020-01-01 至 2023-01-01",
    "交易品种": "沪深300成分股",
})

# 添加绩效指标
builder.add_metrics([
    {"label": "总收益率", "value": "25.6%", "is_positive": True},
    {"label": "年化收益", "value": "18.3%", "is_positive": True},
    {"label": "最大回撤", "value": "-12.4%", "is_positive": False},
    {"label": "夏普比率", "value": "1.92", "is_positive": True},
])

# 添加图表
builder.add_chart("收益曲线", equity_curve_html)
builder.add_chart("回撤分布", drawdown_html)

# 保存
builder.save("report.html")
```

## 数据接入方式

### 1. Mock 数据（测试用）

```python
from czsc.mock import generate_symbol_kines

df = generate_symbol_kines(
    symbol='000001',
    freq='日线',
    sdt='20200101',
    edt='20230101',
    seed=42
)
bars = format_standard_kline(df, freq=Freq.D)
```

### 2. 真实数据源（需要自行接入）

```python
# 示例：从数据库读取
def read_bars_from_db(symbol, freq, sdt, edt):
    sql = f"SELECT * FROM kline WHERE symbol='{symbol}' AND dt BETWEEN '{sdt}' AND '{edt}'"
    df = pd.read_sql(sql, conn)
    return format_standard_kline(df, freq=freq)

# 示例：从 AKShare 读取
import akshare as ak
def read_bars_from_akshare(symbol, freq, sdt, edt):
    df = ak.stock_zh_a_hist(symbol, start_date=sdt, end_date=edt)
    return format_standard_kline(df, freq=freq)
```

## 典型工作流程

```
1. 数据准备
   ↓
2. 定义策略（继承 CzscStrategyBase）
   ↓
3. 回测验证（CTAResearch）
   ↓
4. 信号优化（OpensOptimize/ExitsOptimize）
   ↓
5. 生成报告（HtmlReportBuilder）
   ↓
6. 实盘交易（接入交易接口）
```
