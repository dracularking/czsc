# CZSC 主要使用方式

## 主要使用方式

- 方式1：缠论图形分析，直接运行示例脚本生成 HTML 图表；参考 `examples/stock_chan_analysis.py`。
- 方式2：CTA 策略研究，继承 `CzscStrategyBase` 定义开平仓事件，使用 `CTAResearch` 回测；参考 `examples/use_cta_research.py`。
- 方式3：信号优化，使用 `OpensOptimize / ExitsOptimize` 遍历候选信号组合；参考 `examples/use_optimize.py`。
- 方式4：报告输出，使用 `HtmlReportBuilder` 或回测报告函数自动生成可视化报告；参考 `examples/use_html_report_builder.py`。
- 方式5：Web 应用，启动 Streamlit 后输入代码即可分析；参考 `web_app/app.py`。
