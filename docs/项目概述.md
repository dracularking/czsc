# CZSC 项目概述

**CZSC**（缠中说禅）是一个专业的量化交易技术分析工具库，基于缠论理论实现，用于股票市场、期货、数字货币等金融产品的技术分析和策略回测。

版本: 0.10.12 | 作者: zengbin93

---

## 核心功能模块

### 1. 缠论技术分析引擎
| 模块 | 功能 | 价值 |
|------|------|------|
| `czsc.core.CZSC` | 笔、线段、中枢识别 | 核心算法，自动识别价格结构 |
| `czsc.core.RawBar/NewBar` | K线数据对象 | 标准化价格数据处理 |
| `czsc.core.FX/BI/ZS` | 分型、笔、中枢对象 | 缠论基础元素封装 |

### 2. 信号-事件-交易体系
| 模块 | 功能 | 价值 |
|------|------|------|
| `Signal` | 技术指标信号 | 灵活定义交易信号 |
| `Event` | 信号组合逻辑 | AND/OR/NOT 组合信号 |
| `Position` | 持仓策略 | 开平仓条件、止损、超时 |
| `CzscTrader` | 交易执行器 | 模拟真实交易流程 |

### 3. CTA 策略回测框架
| 模块 | 功能 | 价值 |
|------|------|------|
| `CTAResearch` | CTA策略研究 | 完整的回测、优化、报告 |
| `DummyBacktest` | 快速回测 | 无图表的快速验证 |
| `PairsPerformance` | 交易对分析 | 盈亏、胜率、回撤统计 |
| `OpensOptimize/ExitsOptimize` | 信号优化 | 自动寻找最优信号组合 |

### 4. 数据连接器
| 模块 | 功能 | 数据源 |
|------|------|--------|
| `connectors/ts_connector.py` | Tushare 数据 | A股数据 |
| `connectors/ccxt_connector.py` | 数字货币 | 币安等交易所 |
| `connectors/tq_connector.py` | 天勤期货 | 期货数据 |
| `mock.py` | 模拟数据生成 | 快速测试策略 |

### 5. 探索性数据分析 (EDA)
| 模块 | 功能 | 应用场景 |
|------|------|----------|
| `vwap/twap` | 加权均价计算 | 机构常用指标 |
| `cross_sectional_strategy` | 截面多空策略 | 量化因子策略 |
| `remove_beta_effects` | 去除 Beta 影响 | 纯 alpha 因子提取 |
| `monotonicity` | 因子单调性检验 | 因子有效性验证 |

### 6. 可视化与报告
| 模块 | 功能 | 输出 |
|------|------|------|
| `plot_czsc_chart` | 缠论K线图 | 笔、中枢可视化 |
| `KlineChart` | 交互式图表 | 专业级K线展示 |
| `generate_backtest_report` | 回测报告 | 完整的HTML报告 |
| `html_report_builder` | 报告构建器 | 自定义报告模板 |

### 7. 策略开发工具
| 模块 | 功能 | 说明 |
|------|------|------|
| `CzscStrategyBase` | 策略基类 | 标准化策略开发 |
| `CzscJsonStrategy` | JSON策略 | 无代码策略配置 |
| `signals/` | 信号库 | 内置100+技术信号 |

### 8. 高级功能
| 模块 | 功能 | 特点 |
|------|------|------|
| `WeightBacktest` | 权重回测 | Rust加速的回测引擎 |
| `sensors/` | 市场监控 | 实时监控市场状态 |
| `features/` | 特征工程 | 机器学习特征提取 |
| `utils/cache.py` | 磁盘缓存 | 数据缓存加速 |

## 使用路线推荐

### 快速入门路线
1. **数据获取** → `mock.generate_symbol_kines` 或数据连接器
2. **缠论分析** → `CZSC(bars)` 自动识别笔和中枢
3. **可视化** → `plot_czsc_chart` 查看分析结果

### 策略开发路线
1. **定义信号** → `Signal` 创建自定义信号
2. **组合事件** → `Event` 设置开平仓条件
3. **构建策略** → 继承 `CzscStrategyBase`
4. **回测验证** → `CTAResearch` 执行回测
5. **优化改进** → `OpensOptimize` 寻找最优参数

### 量化研究路线
1. **因子开发** → `eda.py` 中的因子处理函数
2. **截面分析** → `cross_sectional_strategy` 多空组合
3. **特征工程** → `features/` 模块提取ML特征
4. **机器学习** → 结合 sklearn 训练模型

## 项目亮点

1. **缠论实现完整** - 自动识别分型、笔、线段、中枢
2. **信号系统灵活** - 支持复杂逻辑组合
3. **回测框架专业** - 包含手续费、滑点、资金管理等
4. **性能优化** - Rust 核心加速计算
5. **数据源丰富** - 支持A股、期货、数字货币
6. **可视化强大** - 专业的K线图和报告
